# TensorFlow Image Classification and TFLite Quantization

[![TensorFlow](https://img.shields.io/badge/TensorFlow-2.10.0-orange.svg)](https://tensorflow.org)
[![Python](https://img.shields.io/badge/Python-3.8-blue.svg)](https://python.org)
[![TFLite](https://img.shields.io/badge/TFLite-INT8_Quantized-green.svg)](https://www.tensorflow.org/lite)

This repository provides reproducible training pipelines, model export utilities, and a TFLite INT8 quantization workflow for deploying image classification models on edge devices.
---


## Requirements

- OS: Windows or Linux
- TensorFlow:
  - Windows supports up to TensorFlow 2.10. GPU support is not available for versions > 2.10 on Windows.
  - No specific limitations for Linux.
- Python 3.8 (virtual environment recommended)
- For GPU: compatible CUDA and cuDNN versions for the installed TensorFlow build

Install dependencies:

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## Quick start

Check GPU availability:

```bash
python test/GPU_test.py
```

Run the MNIST end-to-end example:

```bash
python test/test.py
```

This example converts MNIST to 32x32 RGB, trains a small MobileNetV2 model, and exports everything (TFLite, labels, plots) to a timestamped folder under `model/`.

Train with `train.py` (command line):

```bash
# Edit `base_dir` in train.py to point to your dataset root containing `train/` and `val/`
python train.py
```

`train.py` runs a two-stage training process and exports all artifacts (tflite, h5, labels, curves, matrix) to a dedicated folder.

Evaluate a .tflite model:

```bash
# Modify MODEL_PATH and TEST_DIR in model_test.py. Results are saved to the model's folder.
python model_test.py
```

`model_test.py` loads the specified `.tflite`, evaluates images, and saves the accuracy bar chart directly into the model's subdirectory.

---

## Output conventions

Models are exported to timestamped sub-directories under `model/model_YYYYMMDD_HHMM/` containing:
- `model_YYYYMMDD_HHMM.tflite`: Quantized TFLite model.
- `stage1_model.h5`: Intermediate H5 model.
- `stage2_model.h5`: Fine-tuned original H5 model (recommended for further training).
- `labels.txt`: Class labels.
- `confusion_matrix.png`: Validation confusion matrix.
- `training_curves.png`: Training loss and accuracy plots.
- `*_accuracy_bar_chart.png`: Test evaluation results (generated by `model_test.py`).
